# NVIDIA Internship 2026 – Learning Journal

This repository documents my journey through the **NVIDIA Internship 2026**, highlighting the skills, experiments, and projects I completed during the program.

The internship focused on:
- Kubernetes and cloud-native environments
- Machine Learning and Deep Learning
- Image Classification with modern AI frameworks
- Generative AI and Transformers
- AI-assisted Web and App Development
- Computer Vision workflows

---

## Core Focus Areas

- Cloud & Kubernetes: Deployment, orchestration, containerized workflows
- Machine Learning: Regression, classification, predictive modeling
- Deep Learning: Neural networks, CNNs, advanced architectures
- Generative AI: Transformers, GANs, diffusion models, LoRA fine-tuning
- AI-Assisted Development: Prompt engineering, Antigravity IDE, automated app/web design
- Computer Vision: Dataset preparation, training, inference with Roboflow
